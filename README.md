## 🔒 Security Checks Performed

1. **HTTPS/SSL Verification** - Ensures encrypted connection
2. **Phishing Pattern Detection** - Identifies common phishing indicators
3. **Malware Indicators** - Scans for malware-related patterns
4. **Domain Reputation** - Checks against known safe/malicious lists
5. **URL Structure Analysis** - Validates URL format and structure
6. **Obfuscation Detection** - Identifies hidden redirect attempts
7. **Homograph Attack Detection** - Finds Unicode character spoofing
8. **Keyword Analysis** - Scans for suspicious terms

### Threat Patterns Detected

- URL shorteners (bit.ly, tinyurl, etc.)
- Phishing keywords (verify, urgent, suspended)
- IP addresses instead of domains
- Free TLD domains (.tk, .ml, .ga, .cf, .gq)
- Excessive subdomains
- Unusually long domains
- URL obfuscation (@, special characters)
- Homograph attacks (lookalike characters)

## 🎯 How It Works

### 1. URL Analysis
```javascript
User enters URL
    ↓
Validate format
    ↓
Analyze with 8 security checks
    ↓
Calculate risk score
    ↓
Determine status (safe/suspicious/malicious)
    ↓
Generate detailed report
```

### 2. Screenshot Generation
```javascript
If status is safe or suspicious:
    ↓
Try primary service (Thum.io)
    ↓
If fails → Try service #2
    ↓
If fails → Try service #3
    ↓
Continue through 5 services
    ↓
Display first successful screenshot
```

### 3. Threat Detection
- Pattern matching (regex)
- Keyword analysis
- Domain checking
- Structure validation
- Protocol verification
- Reputation lookup

### Understanding Results

**🟢 SAFE**
- Low risk (0-29 points)
- HTTPS enabled
- Trusted domain
- No threats detected

**🟡 SUSPICIOUS**
- Medium risk (30-59 points)
- Some concerns
- Proceed with caution
- Verify authenticity

**🔴 MALICIOUS**
- High risk (60+ points)
- Multiple threats
- DO NOT VISIT
- Likely dangerous

## 🐛 Troubleshooting

### Screenshot Not Loading
- Service may be slow
- Try refreshing
- System tries 5 services

### Scan Shows Error
- Check URL format
- Ensure valid domain
- Try adding https://
- Check internet connection

### Theme Not Saving
- Enable localStorage
- Check browser settings
- Clear cache and retry
